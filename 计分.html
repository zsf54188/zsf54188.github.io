开篇立论
（20分）		 0-10分：吐字模糊，语言繁琐缺少逻辑，缺少论据，对论题无正确认知理解或立论偏离论题。
10-20分：吐字清晰，语言简洁且表达通顺，论据有信服力，分析角度有说服力和逻辑性，对论题有正确理解。		 / / / 0
攻辩
（20分）		 0-3分：吐字模糊，语言繁琐缺少逻辑，回避对方提问或对对方已回答的问题抓住不放。
4-7分：吐字较清晰且能用简练语言提问回答，思维明晰，能抓住对方发言漏洞辩驳。
8-10分：吐字清晰且能用精炼的语言提问或回答，可以合理的引用实例进行辩驳或能够围绕己方观点进行辩驳。		 / / 0
攻辩小结
（10分）		 0-5分：未全面归纳解读对方的矛盾对错且缺少正确辩驳和追击，没有基于攻辩形式进行对己方观点的进一步阐述或阐述不到位。
6-10分：能够细节抓住对方的失误进行辩驳追击，有对己方观点有进一步陈述，辩护语言有理有据信服力强。		 / / / 0
自由辩论
（20分）		 0-1分：攻防轮换混乱且不能针对对方的论点和论据进行系统反驳，语言表达模糊不明确。
2-3分：反应机敏，语言简练且辩论思路清晰，能够对对方发言漏洞进行辩驳。
4-5分：可以合理的引用实例进行辩论，语言有感染力且能够针对对方的论点进行发言。		 0
总结陈词
（20分）		 0-10分：未能合理正确的总结己方的立场且未对对方的论点进行合理反驳。
10-20分：可以全面总结本方的立场并系统反驳对方的进攻，为本方辩护。语言表达有说服力且能够和开篇理论首尾呼应。		 / / / 0
